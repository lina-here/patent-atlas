## 2. R composition vs M49 continents

Continent = M49 region, Americas split by sub-region 021 (Northern America) vs 419. Member sums over WIPO country
codes (aggregates, regional offices, former states excluded unless noted).

PCT (pct_origin):
- R1, R2, R5, R6 = M49 member sum exactly, every year 1995-2025. CY, TR, IL, AM, AZ, GE, KZ in Asia; RU in Europe
  (= M49).
- R4 = member sum + AN (Netherlands Antilles) exactly (AN non-null 2004-2011, values 1-2).
- R3 - member sum: 12-36 per year 1997-2006 (likely YU / Serbia-Montenegro era origins WIPO counts but does not list
  in pmh: pmh lists no YU/CS/SU/DD/ZR, RS from 2006), 0-4 in 2007-2025, 0 in 1995-1996.
- ZZ - sum(R1..R6) = `**` Unknown exactly, every year (min 24 2010, max 299 2019). Never negative.

Office (office_apps), 1997-2024:
- WD = sum(R1..R6) exactly every year (difference 0).
- Regional offices: EP, EA -> R3 Europe; OA, AP -> R1 Africa; GC -> R2 Asia. EA in Europe fits (Europe residual
  max 0.22% vs 1.3% with EA in Asia). YU office (to 2003) -> Europe.
- Country placement = M49: TR (office 2024: 10,351), IL (8,262), KZ (1,121) would leave residuals far above the
  measured ones if WIPO put them elsewhere; RU in Europe.
- Residual (R - member sum incl. regional offices)/R, 1997-2024: R1 Africa -3.4% (2018) .. +15.6% (1997); R4 LAC
  +0.4% .. +9.9% (1998); R2 Asia -0.0% .. +0.9% (2008; +8.5k-10.5k in 2008, 2012-2016, 2021); R3 Europe -0.01% ..
  +0.22%; R5 -0.01% .. +0.02%; R6 -0.13% .. +0.34%. Reading: R totals include WIPO estimates for non-reporting
  offices (2024 null country offices: Africa 34, LAC 10, Oceania 11, Asia 8, Europe 4, N. America 0) plus small
  revisions. Member sums cannot reproduce R; cross-check needs a tolerance.

Origin (origin_apps), no R rows -> member sums. Unallocated = WD (office world, `SHARE_DENOMINATOR`) - sum of
continent member sums:
- Never negative (min 37,716). Share of WD: 1985-1993 0.33-0.50; 1994-2003 0.085-0.129; 2004-2024 0.011-0.077.
- Cause 1985-1993: WIPO's by-origin "Abroad" counts are near-empty before 1994 (world sum of Abroad: 1985-1992
  500-2,200/yr; 1993 7,514; 1994 243,947). US origin total 1993 105,208 -> 1994 173,841; JP Abroad 1992 14 ->

  too (step in 1994).
- Historical states (SU, YU, DD, CS, ZR) sit in unallocated: 1985-1990 120k-191k/yr, 1991 25k, after 1992 < 600.

Negative unallocated years: none in any series.

## 4. Sources: UN M49, world-atlas

UN M49:
- URL https://unstats.un.org/unsd/methodology/m49/overview/ ; format: HTML page with one table per language
  (`#downloadTableEN`, 248 rows; CSV/Excel buttons are client-side exports of that table). Columns: Global Code/
  Name, Region Code/Name, Sub-region Code/Name, Intermediate Region Code/Name, Country or Area, M49 Code,
  ISO-alpha2, ISO-alpha3, LDC, LLDC, SIDS. No "last updated" stamp on page.
- Terms: page links UN terms of use (https://www.un.org/en/about-us/terms-of-use): download/copy for "personal,
  non-commercial use, without any right to resell or redistribute them or to compile or create derivative works";
  "as is". -> Do not commit the table or a copy of it. Store only our code -> group mapping (ISO2 -> region id,
  continent; region ids/labels) with source URL + retrieval date (spec's fallback).
- M49 codes are 3-digit zero-padded strings ("004", "010") = world-atlas ids.
- Current table: GG 831, JE 832 sit directly in sub-region 154 (no intermediate region 830 any more). Intermediate
  regions exist only under 419 (005, 013, 029) and 202 (011, 014, 017, 018).
- AQ row: Region empty. TW: not in M49.

world-atlas:
- npm `world-atlas` 2.0.2 (latest 2.x), ISC licence (copyright Michael Bostock; notice must stay with copies),
  Natural Earth 4.1.0 admin-0 (public domain). Files `countries-110m.json` 107,761 B (gzip 38,423),
  `countries-50m.json` 756,420 B (gzip 230,118), `countries-10m.json` 3,661,071 B. 50m countries-only (no `land`
  object, unused arcs dropped) 743,418 B; without Antarctica 698,398 B: still > 500 KB.
- Id scheme: `id` = ISO 3166-1 numeric string; `properties.name`. No "-99": France 250, Norway 578 carry ids.
  Features without `id`: 110m N. Cyprus, Somaliland, Kosovo; 50m same + Indian Ocean Ter., Siachen Glacier.
  50m duplicate id 036 (Australia + Ashmore and Cartier Is.).
- Taiwan feature id 158 at 110m and 50m (not an M49 code).
- Multi-territory features: France 250 incl. French Guiana (110m; 50m also Guadeloupe, Martinique, Réunion,
  Mayotte); Norway 578 incl. Svalbard; Netherlands 528 at 50m incl. Caribbean Netherlands (why BQ has no own
  feature); USA incl. Alaska, Hawaii.
- Antarctica: id 010 at both resolutions (no WIPO code -> neutral per spec rule).
- Features with an M49 id but no WIPO entity (neutral grey): 110m AQ, EH W. Sahara, FK, GL Greenland, NC, PR
  Puerto Rico, PS Palestine, TF; 50m adds 26 more (AI, AS, AW, AX, BL, BM, FO, GS, GU, HM, IM, IO, JE, KY, MF,
  MP, MS, NF, PF, PM, PN, SH, TC, VG, VI, WF).
- `entities.json` countries (202) with no feature: 110m 37 = AD AG BB BH BQ CK CV CW DM FM GD GG HK KI KM KN LC LI
  MC MH MO MT MU MV NR NU PW SC SG SM ST SX TO TV VA VC WS (all but GG have data in some type; total-row data:
  not BQ, SX); 50m 2 = BQ, TV; 10m has TV (798), still no BQ.
- Resolution: 50m > 500 KB -> 110m. Featureless countries with a total value in some series then need dots
  (34 today; BQ, SX have none): centroid of their 50m feature (TV: 10m), computed at geo build from the same
  world-atlas package; a featureless country with data but no feature at any resolution (BQ if it ever reports)
  -> "not drawn on map" list. Dots are needed for SG, HK, MT, LI, MC etc. even at 50m (specks
  at world scale).
